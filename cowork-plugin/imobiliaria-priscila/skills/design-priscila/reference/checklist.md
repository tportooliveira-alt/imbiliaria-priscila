# ✅ Checklist "está no sistema?" — gate de revisão de tela

Passe QUALQUER tela/seção por isto antes de publicar. Se UM item falhar, a tela está "desordenada" — corrige.

- [ ] **Espaço:** todo padding/margin/gap é um valor da escala 8pt (4/8/12/16/24/32/48/64/80)? Nenhum "13px no olho"?
- [ ] **Ritmo:** espaço ENTRE blocos ≥ espaço DENTRO deles? Padding vertical da seção é o mesmo das outras seções?
- [ ] **Tipo:** todo texto usa um dos ~6-7 papéis da type scale? Playfair só em título, Inter no resto? Nenhum tamanho avulso?
- [ ] **Cor:** ≤ 4 cores principais na tela? Dourado aparece como **acento escasso** (1 destaque/seção), não como fundo grande?
- [ ] **CTA:** existe **UMA** CTA primária clara? As demais são ghost/secundárias, sem competir?
- [ ] **Botões:** todos usam uma das 3 variantes (primary/gold/ghost) com mesmo padding, raio e altura?
- [ ] **Grid:** tudo alinha ao mesmo container e às mesmas colunas? Cards no mesmo grid com mesmo gap?
- [ ] **Card de imóvel:** mesma proporção de imagem e mesma ordem interna (preço/localização dominam) em todo lugar?
- [ ] **Elevação:** sombras só dos 3 níveis? Raio só da escala (sm/md/lg/pill)?
- [ ] **Above-the-fold:** hero tem só imagem + busca + 1 CTA? Sem propostas concorrentes?
- [ ] **Mobile:** alvos de toque confortáveis (≥44px), texto legível, formulário enxuto?
- [ ] **Token, não valor:** nada usa cor/tamanho/espaço "cru" — tudo aponta para uma variável de `:root`?

**Regra de bolso:** escalas finitas + papéis nomeados + um componente por padrão = site com sistema (não bagunçado).
