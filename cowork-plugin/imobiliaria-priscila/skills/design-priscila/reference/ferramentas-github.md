# 🧰 Ferramentas/referências de design (GitHub) — pra a skill

Da deep-research verificada (16/06). Use quando precisar gerar tokens, escalas de cor, ou referência de estrutura.

## Pra gerar/organizar tokens e cores (navy + dourado)
- **Radix Colors** (radix-ui.com/colors/custom) — escalas de 12 passos; gera navy/dourado consistentes com contraste.
- **uicolors.app/generate** — rápido: dá uma cor, sai a escala (50–950). Bom pra preencher `tokens.css`.
- **Adobe Leonardo** (github.com/adobe/leonardo) — paletas por contraste (acessibilidade), DTCG→CSS.
- **Style Dictionary** (github.com/style-dictionary/style-dictionary) — se formalizar tokens em build: tokens → CSS vars.
- **DTCG** — spec W3C de design tokens, 1ª versão estável (out/2025) — formato-padrão se exportar tokens.

## Referência de abordagem (design como markdown p/ agente)
- **Anthropic `frontend-design` plugin** (github.com/anthropics/claude-code/tree/main/plugins/frontend-design) — plugin
  oficial; CSS variables + acento por cor dominante. **Estudar e alinhar nossa skill.**
- **VoltAgent awesome-design-md / awesome-claude-design** — design system como markdown legível por agente (valida nossa abordagem).
