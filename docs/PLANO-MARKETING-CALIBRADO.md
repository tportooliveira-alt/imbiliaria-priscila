## 👥 Dois funis distintos (gerir separado)
- **COMPRADOR**: anúncio → site → calculadora/contato → Ana qualifica → visita → venda.
- **VENDEDOR (captação) = o ATIVO** (cresce a carteira): avaliação grátis → lead vendedor → roteiro consultivo
  (referencia o imóvel + dados de mercado + dor + proposta + CTA visita) → **captação** → laudo pago. _É pipeline próprio._
